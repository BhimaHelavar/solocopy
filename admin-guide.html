SoloCopy admin guide

For office IT teams: how to install SoloCopy on many PCs, control it with Group Policy or Intune, and where it keeps its files. All these features are free.

Formerly “Found Duplicate”. Only the visible name changed. These stay the same, so existing installs, history and policies keep working: the registry key SOFTWARE\Policies\FoundDuplicate, the template files FoundDuplicate.admx / FoundDuplicate.adml, the data folder %LOCALAPPDATA%\FoundDuplicate and the MSI upgrade code (the SoloCopy MSI replaces an installed Found Duplicate). The program is now SoloCopy.exe in C:\Program Files\SoloCopy.

Safety rules users cannot turn off

  • Recycle Bin only. The app never deletes a file permanently.
  • Always keeps one copy. If a selection would remove every copy of a file, that group is skipped.
  • No deletes on network or USB drives. Windows would delete files there permanently. The app can still search them.
  • Skips changed files. If a file's size or modified time changed after the search, it is left alone.
  • Leaves very long paths in place. The Recycle Bin cannot take paths longer than 260 characters.

Every delete request is written to the delete history (audit log). Users see it under History and can export it as CSV or PDF.

The four policies

All settings live under HKLM\SOFTWARE\Policies\FoundDuplicate (computer) or HKCU\SOFTWARE\Policies\FoundDuplicate (user). If a value is set in both, the computer value wins. A missing value means “not configured”. The app re-reads the policy before every search and every delete, so after gpupdate no restart is needed.

PolicyRegistry value and typeEffectExample
Turn off deleting (report-only mode)DisableDelete, REG_DWORD1 = users can search, view History and export, but nothing can be moved to the Recycle Bin. 0 or missing = deleting works as normal.1
Allow searching only in these foldersAllowedFolders, REG_MULTI_SZSearches are allowed only inside these folders and their subfolders. Environment variables are expanded. Empty or missing = no limit.%USERPROFILE%\Documents and D:\Shared\Team
Block searching network drivesBlockNetworkDrives, REG_DWORD1 = searching UNC paths and mapped network drives is refused. 0 or missing = allowed.1
Delete history (audit) folderAuditLogFolder, REG_EXPAND_SZThe delete history is written to this folder instead of the local one. If it cannot be reached, the app writes locally, logs a warning and still finishes the delete. No entry is lost.\\fileserver\audit$\%USERNAME%
  • For the audit folder, users need permission to create files and add to them, not to delete or change them.
  • AllowedFolders limits what the app searches; it is not a security boundary. Use NTFS permissions to protect data. Write each folder as a full path.
  • DisableDelete and BlockNetworkDrives count as on when set to a value the app cannot read, so a typo never loosens them.

Deploy with Group Policy

The MSI puts the templates in C:\Program Files\SoloCopy\policy\: FoundDuplicate.admx and en-US\FoundDuplicate.adml.

  1. Copy FoundDuplicate.admx to \\<domain>\SYSVOL\<domain>\Policies\PolicyDefinitions.
  2. Copy FoundDuplicate.adml to the en-US folder inside it.
  3. In Group Policy Management, edit a Group Policy Object.
  4. Go to Computer Configuration > Administrative Templates > SoloCopy (per PC) or User Configuration > Administrative Templates > SoloCopy (per user).
  5. Set the policies and link the GPO to the right OU.
  6. On a test PC, run gpupdate /force and check what applies.

On a single PC without a domain, copy the files to C:\Windows\PolicyDefinitions (and its en-US folder) and use gpedit.msc. Windows Home editions do not have gpedit.msc.

Deploy with Intune

The app

  • Line-of-business app (simplest): Apps > Windows > Add, type Line-of-business app, upload the .msi, assign it to a device group.
  • Win32 app (more control): pack the .msi with the Microsoft Win32 Content Prep Tool. Install command msiexec /i SoloCopy-1.0.0-x64.msi /qn, uninstall command msiexec /x {ProductCode} /qn, install behaviour System, detection rule MSI with the product code.

The policies

  1. Devices > Configuration > Import ADMX: upload FoundDuplicate.admx and FoundDuplicate.adml (both are needed).
  2. When the import shows it is available, create a profile: Windows 10 and later, Templates > Imported Administrative templates.
  3. Pick the SoloCopy template, set the policies, and assign the profile.

Silent install and uninstall

The MSI installs per machine to C:\Program Files\SoloCopy, so run these as administrator or from a tool that runs as SYSTEM.

msiexec /i SoloCopy-1.0.0-x64.msi /qn /l*v install.log
msiexec /x SoloCopy-1.0.0-x64.msi /qn
msiexec /x {ProductCode} /qn

To find the product code on a PC where the app is installed (PowerShell):

Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\* |
  Where-Object DisplayName -eq 'SoloCopy' |
  Select-Object PSChildName, DisplayVersion

Installing a newer MSI replaces the old version. Installing an older version over a newer one is refused. Uninstalling keeps each user's data folder. No .NET install is needed; the WebView2 Runtime is part of Windows 10 and 11. For PCs without internet, install Microsoft's WebView2 Evergreen Standalone Installer first.

Check what applies

  • When any policy is set, the app shows Managed by your organization.
  • Copy diagnostics copies the effective policy, versions, folders and the last 200 log lines.
  • The log records the effective policy each time the app starts.
  • Raw values: reg query HKLM\SOFTWARE\Policies\FoundDuplicate and reg query HKCU\SOFTWARE\Policies\FoundDuplicate.

For a quick test without Group Policy, set a value from an administrator PowerShell while signed in as the test user, for example report-only mode:

reg add HKCU\SOFTWARE\Policies\FoundDuplicate /v DisableDelete /t REG_DWORD /d 1 /f
reg delete HKCU\SOFTWARE\Policies\FoundDuplicate /f

Where data lives

Everything is per Windows user, under %LOCALAPPDATA%\FoundDuplicate:

File or folderWhat it is
audit\audit-YYYY-MM.jsonlThe delete history: one JSON line per file in every delete request (date, user, PC, path, size, result, content SHA-256, kept copy). Lines are only ever added. If AuditLogFolder is set, new lines go there instead.
logs\app-YYYYMMDD.logDaily log: app start, versions, searches, delete summaries and errors. Kept 14 days. File contents are never logged.
settings.jsonThe user's last folder, search options and language. If missing or damaged, the app uses the defaults.
WebView2\Data for the browser engine that draws the app window.

With the Microsoft Store version, Windows may keep these files under %LOCALAPPDATA%\Packages\ instead. Copy diagnostics shows the folders the app really uses.

Privacy

Nothing leaves the PC, except the delete history when you set AuditLogFolder; it goes only to the folder you choose. There is no telemetry, and the app window does not load pages from the internet. See the privacy policy.
