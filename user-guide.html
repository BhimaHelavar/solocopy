SoloCopy user guide

SoloCopy finds duplicate files in a folder and moves the extra copies to the Recycle Bin. This guide explains each step in plain language.

For Read & summarise (reading and summarising documents with AI, coming in a future version), see the AI guide.

Install SoloCopy

  1. Download the .msi file from the download section. Only install files from this website, the Microsoft Store or the official release page.
  2. Optional but recommended: check the file. Open PowerShell in the download folder and run the command below. Compare the result with the line for that file in SHA256SUMS.txt. If they are not the same, do not install the file. 
    Get-FileHash .\SoloCopy-0.9.0-x64.msi -Algorithm SHA256
  3. Double-click the .msi file and follow the steps. Windows asks for admin rights, because the app is installed for all users of the PC.
  4. Start the app from the Start menu: SoloCopy.

You do not need to install .NET. The app needs the Microsoft Edge WebView2 Runtime, which is built into Windows 11 and already on Windows 10 PCs that get updates. If it is missing, the app offers to open the download page when it first starts.

“Windows protected your PC” (SmartScreen)

Until the app is signed with a paid code-signing certificate, Windows may show Windows protected your PC when you open the downloaded installer.

  • If you got the file from an official place and the checksum matches, click More info, then Run anyway.
  • If you are not sure where the file came from, do not run it.

Even with a paid certificate, the warning can still appear for a while. It goes away as more people install the app.

Step 1: Choose a folder

Click Choose a folder and pick the folder to check, for example your Documents folder or a shared office folder on this PC. The panel also shows SoloCopy's promises: nothing is deleted until you confirm, deleted files go to the Recycle Bin, and at least one copy of every file is always kept.

Step 2: Search

Choose what to look for:

  • Exact copies (recommended): files with exactly the same content, even if their names are different. These are safe to remove.
  • Files with the same name: for example “Report.pdf” and “Report (1).pdf”. They may be different versions, so you decide which to keep.

Settings you rarely need are under More options:

  • Also check folders inside this folder (subfolders).
  • Treat “Report (1)”, “Report - Copy” and “Copy of Report” as the same name.
  • Include hidden and system files (not recommended).
  • Only these file types, for example pdf, docx, xlsx. Leave it empty to check all files.

Click Search for duplicates. A progress bar shows while SoloCopy searches. Click Stop to cancel; nothing is changed.

Step 3: Review and clean up

The results show how many files were checked, how many extra copies were found, and how much space can be freed.

Exact copies tab

Quick clean up marks every extra copy for you. First choose which copy to keep:

  • the oldest copy (the original),
  • the most recently changed copy, or
  • the copy in the main folder (shortest path).

Then click Mark extra copies. You can still change any file below.

Keep or Delete

Every file has a Keep / Delete switch. Click Open folder to look at a file in File Explorer first. SoloCopy will not let you mark the last kept copy: choose Keep on another copy first.

Same name, check first tab

Files here have the same name but may have different content, for example an old and a new version of a letter. Each file is marked “Same content as another file here” or “Different content”. Nothing is selected on its own: look at the files and choose Keep or Delete yourself.

Move to the Recycle Bin

The bar at the bottom shows how many files are marked and how much space they free. Click Move to Recycle Bin, check the summary, and click Yes, move to Recycle Bin.

A report then says what was moved and lists any file that was left in place, with the reason. SoloCopy leaves a file in place when:

  • it changed after the search (search again first);
  • deleting it would remove the last copy;
  • it is on a network or USB drive, where Windows would delete it permanently;
  • its path is too long for the Recycle Bin (more than 260 characters).

Get files back

Files that SoloCopy deletes go to the Windows Recycle Bin. To get one back, use either way:

  • In SoloCopy, open History, select the files and click Restore. They go back to where they were.
  • Or open the Recycle Bin on the desktop, right-click the file and choose Restore.

Once the Recycle Bin is emptied, files cannot be restored. Keep your own backups of important files.

History and export

Click History at the top of the app to see every file that someone asked to delete on this PC and what happened to it. Click Back to search to return.

  • Export to CSV saves the full history as a file you can open in Excel.
  • Export to PDF saves a report you can print or share.

The file is saved only where you choose. SoloCopy does not send it anywhere.

Copy diagnostics

If something goes wrong, click Copy diagnostics at the top right. It copies the app and Windows versions, the app's folders and the most recent log lines to your clipboard, ready to paste into an email to support or your IT team. Nothing is sent by the app. Check the text before you share it: it can contain folder and file paths. See Support.

At work: rules from your IT team

If you see Managed by your organization, your IT team has set rules for SoloCopy. For example, in report-only mode you can search, view History and export, but you cannot move files to the Recycle Bin. Your IT team may also limit which folders can be searched, or block network drives. Ask them if something is not allowed.

Update or uninstall

  • Update: install the newer MSI over the old one. You do not need to uninstall first.
  • Uninstall: Settings > Apps > Installed apps > SoloCopy > Uninstall.

Uninstalling keeps your delete history, logs and settings in %LOCALAPPDATA%\FoundDuplicate on purpose, because the history may be needed later. Delete that folder by hand if you want it gone. (The folder keeps the app's former name, Found Duplicate.)
