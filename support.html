Getting help with SoloCopy

Ask for help

Email: support.solocopy@gmail.com

In an office, ask your IT department first. They may have set rules for the app (for example, report-only mode).

What to include

  1. Diagnostics. In the app, click Copy diagnostics. Then paste it into your email (press Ctrl+V). Check the text first: it can contain folder and file paths.
  2. App version. You can see it in About in the app. It is also in the diagnostics text.
  3. Windows version. For example, Windows 11 24H2. Press Windows key + R, type winver and press Enter to see it.
  4. What you did. The steps, one by one.
  5. What you expected, and what happened instead. Copy the exact error message, or add a screenshot.

Please do not send other people's personal files.

Where the app keeps its files

Everything is in %LOCALAPPDATA%\FoundDuplicate. Type %LOCALAPPDATA%\FoundDuplicate in the File Explorer address bar to open it.

Folder or fileWhat it is
logs\app-YYYYMMDD.logLogs, one file per day, kept for 14 days. No file contents.
audit\audit-YYYY-MM.jsonlDelete history, one file per month.
settings.jsonYour settings.

If you installed SoloCopy from the Microsoft Store, Windows may keep these files under %LOCALAPPDATA%\Packages\ instead. Copy diagnostics shows the folders the app really uses.

Support may ask you for a log file. Send it only if you are happy to share what is in it.

Security problems

Do not report security problems in public, or as a normal support question. Report them privately by email to support.solocopy@gmail.com and write in the subject that it is a security report.

Support for organisations

The app is free. Organisations that need priority support, deployment help or custom terms can buy paid support. Write to support.solocopy@gmail.com.
