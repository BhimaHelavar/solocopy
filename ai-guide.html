Read & summarise: AI guide

Coming in a future version. Read & summarise is being tested and is not in public beta 0.9.0. This guide shows how it will work. Screens and names may still change before release.

Read & summarise reads the documents in a folder (PDF, Word, Excel, scans and photos) and tells you what it could not read. It then makes a summary that shows the file and page each line comes from. From that you can make an Excel table, an office note, a list of deadlines, a report, a presentation or an email draft.

Your files are only read, never changed, moved or deleted.

Open Read & summarise

In SoloCopy, open the Tools menu and choose Read & summarise. The screen has five steps: Choose a folder, Read, Summary, Questions and Create. If nothing was unclear, the Questions step is left out and Create becomes step 4.

If you see “The doc reader is not installed on this PC”, the reading part is missing. Ask your IT team to install it.

Set up AI (do this once)

Open Tools > AI settings, or click AI settings… in step 1. Under How should SoloCopy use AI? choose one of these:

ChoiceWhat it meansGood for
Let SoloCopy choosePicks the best mode for this PC. The one it suggests is marked “Suggested for this PC”.Most people
OfflineEverything stays on this PC.PCs with about 16 GB of memory or more
Offline (light)Everything stays on this PC, with a smaller AI.PCs with less memory
HybridFiles are read on this PC. Only a masked summary request goes to the online AI (Google Gemini).Faster summaries on PCs that are too slow for Offline

AI on this PC (Offline and Offline light)

  1. Install Ollama on the PC and download a model, for example qwen2.5:7b-instruct. llama.cpp works too.
  2. In Server address, keep http://127.0.0.1:11434/. The address must be on this PC; SoloCopy refuses any other address.
  3. Pick the Model for Offline and the Model for Offline (light).
  4. Click Connect. You should see “Connected: …, answered in N s.” Then click Save.

Online AI (Hybrid)

  1. Choose Hybrid and tick Only a masked summary request goes to Google Gemini; files are always read on this PC. Hybrid cannot be used without this tick.
  2. Get an API key at aistudio.google.com and paste it in API key. The key is saved encrypted for your Windows account and is never shown again. To delete it, click Remove key.
  3. Click Load models and pick a model, or choose “Another model” and type its name.
  4. Click Connect to try it, then Save.

Click Back to Read & summarise to return; the folder you chose is kept.

Step 1: Choose a folder

Click Choose folder… and pick the folder of documents. The top of the step shows:

  • the AI mode, for example “AI: On this PC (light)”. “set by your IT admin” means your IT team chose it;
  • “Pro: no file limit”, or how many trial files are left, with a Get Pro link.

Click Read the documents.

Step 2: Read

A live count shows how far reading has got, for example:

7 files found = 5 read + 0 waiting for you + 2 could not be read

Every file in the folder is counted, so nothing is silently skipped. Click Stop reading to stop; what was read so far is kept, and Read again goes on from there. When reading ends, click Show the files that were not read to see each one and the reason.

About your files

This part helps you check what each file is and what it says.

  • What kind of documents are these? Pick the kind, for example invoices, court orders, government letters, bank documents (cheque, passbook), ID documents, certificates or receipts. Or choose Detect automatically and click Check the files. Each file gets a type with “How sure”. A badge shows whether the type came from the AI (“AI suggestion”) or the file name (“From file name”). Files marked Please check need you to look; you can change any file's type.
  • + Make my own category… for a kind of document that is not listed. Give it a name, for example “Gate pass”, and the details to find, for example “Visitor name, Valid till, Vehicle number”.
  • Score. Each file shows how many of the details for its kind were found in it or entered by you. Under To raise the score, type what you know that the file does not say. Checked means every test passed; Needs review lists the checks that did not pass.
  • Remove from this run leaves a file out of the score and the results. Nothing is deleted from your computer. Put back includes it again.
  • Describe each file gives a short description of every file, by its type, with the page each value is on. A value the AI gave but that is not in the file is marked not confirmed; check the file before you use it. A value that was read but does not look right is marked please confirm and is not used in any result until you click Accept or type the right value.
  • Ask about your files. Type a question, for example “What is the next hearing date?” or “What are the account number and IFSC?”, and click Ask. Answers come only from your files and show the file, the page and the words they are based on.

Step 3: Summary

Click Summarise. You get The folder at a glance and a summary File by file. Every line shows the file and page it comes from, so you can check it.

Below that are the Facts found: files, pages, dates, amounts, case numbers, file numbers, letter numbers and open questions. A line at the end says where the summary was made: “Made on this PC. Nothing left this PC.” or “Made with online AI.”

If the AI is not available, no summary is made, but the facts and the Create step still work.

Step 4: Questions

When the reader was not sure about some text, for example a smudged number on a scan, it asks you. Each question shows the picture of that spot, what was read (“Read as: …”) and how sure the reader was. Type what it really says in What does it say? and press Enter or Save; the next question opens. Your answers are used in the summary and in everything you create.

Step 5: Create

  1. Under What do you need from these files? choose one:
    • Invoices into Excel: only invoices whose amounts, tax numbers and date pass every check are entered; the rest are listed apart with the reason.
    • A register or table: one row per file with the details you pick, as Excel, CSV and a web page with charts.
    • An office note: a short Word and PDF note of what each file says, the dates to note and what is not found.
    • Dates and deadlines: every hearing, last date and due date in one sorted list with days left, plus a calendar file for Outlook or your phone.
    • Missing information: what the files do not say, with tick boxes, so you know what to ask for.
    • A detailed report: Word and PDF, with a description of each file and where every value was found.
    • A presentation: a PowerPoint with a title slide, an overview and one slide per file.
    • An email draft: a summary written as an email for you to check and send yourself.
  2. Under Save results in, choose a folder. Nothing is saved anywhere else.
  3. Pick which documents and details to include, then click Prepare and preview. A window shows exactly what will be created. Nothing has been written yet.
  4. Click Create. Then use Show in folder to open the result in File Explorer.

How far this result can be trusted shows how many files are ready, for example “Ready 80%”. Files that are not ready are left out of Word, PDF, email and presentation results, and are marked “Needs review” in Excel. To raise it, answer their questions or remove them from the run in About your files.

SoloCopy never sends email. An email is always a draft that you open, check and send from your own mail program.

Scanned papers and photos

Scanned PDFs and photos (PNG, JPG, TIF, BMP) have no text inside them, only a picture of the page. To read them, the doc reader uses OCR, which turns the picture into text on this PC. Text that OCR is not sure about becomes a question in step 4.

If OCR is not set up on the PC, such pages are listed as “needs OCR” and the file shows “No readable text”. You can still set the file's type yourself. Ask your IT team to turn on the OCR reader.

For the best results, scan at 300 dpi, keep pages straight, and photograph documents in good light without shadows.

Where your documents go

  • Files are read on this PC. The documents themselves are never uploaded, including in Hybrid.
  • Offline and Offline (light) send nothing. The AI runs on this PC, and its address must be on this PC.
  • Hybrid sends only a masked request. Names, numbers and addresses are masked first, and Hybrid is used only after you tick the consent box. Your IT team can turn online AI off.
  • Your files are never changed. Results are written only to the folder you choose, and only when you click Create.
  • Saved text is encrypted for your Windows account.

The privacy policy covers public beta 0.9.0. It will be updated to cover Read & summarise before the feature is released.

Trial and Pro

Read & summarise is part of SoloCopy Pro. Without Pro you can try it on a small number of files; step 1 shows how many trial files are left. With Pro there is no file limit.

At work: rules from your IT team

If you see “Your IT team manages some doc reader settings on this PC”, your IT team has set rules. For example, they may allow only some folders, allow only some AI modes, or turn online AI off. Choices they control show “set by your IT admin”, and actions they block show “Your IT team does not allow this here”. Ask them if something is not allowed.

If something goes wrong

  • “The AI is not available right now”: for Offline, check that Ollama is running and click Connect in AI settings. For Hybrid, check the internet connection and that a key is saved. The facts and the Create step still work.
  • Connect shows an error: check the server address (Offline) or the API key and model (Hybrid).
  • A file “could not be read”: it may be password-protected or damaged. Open it in its own program to check.
  • Many questions on a scan: scan it again more clearly, or type the answers in step 4.
