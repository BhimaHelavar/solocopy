SoloCopy — Duplicate File Cleaner

Find duplicate files and move the extra copies to the Recycle Bin. One copy always stays.

Download for Windows Read the user guide

Free for home and work · Windows 10 and 11 · English and हिंदी · Works offline

How it works

  1. Choose a folder

    For example your Documents folder, or a shared office folder on this PC.

  2. Search

    Look for exact copies (recommended), files with the same name, or both. A progress bar with a Stop button shows while SoloCopy searches.

  3. Review and clean up

    See how many extra copies were found and how much space you can free. Use Quick clean up or mark each file Keep or Delete, then move the extra copies to the Recycle Bin.

Safe by design

  • Recycle Bin only. SoloCopy never deletes a file permanently. Deleted files go to the Windows Recycle Bin, and you can put them back.
  • Always keeps one copy. You cannot delete every copy of a file by mistake. The app will not let you mark the last kept copy.
  • Skips changed files. If a file changed after the search, SoloCopy leaves it alone. Search again first.
  • Asks before deleting. You see how many files will be moved and how much space they free, and you confirm.
  • Works offline. No account, no sign-in, no ads and no telemetry. The app makes no network calls.
  • Nothing leaves your PC. Your files, file names and delete history stay on your PC. See the privacy policy.

Features

Exact copies and same names

Finds files with exactly the same content, even when their names differ, by comparing the content itself. Also finds same-name files such as “Report.pdf” and “Report (1).pdf”. These may be different versions, so you decide.

History, CSV, PDF and Restore

Every delete is recorded in History: date, file, size and result. Select files and click Restore to put them back. Export the History to CSV (for Excel) or to a PDF report.

English and हिंदी

Switch the language in the app at any time. PDF reports show Hindi text correctly.

Admin controls for IT

Report-only mode, allowed folders, blocked network drives and a central delete history, set with Group Policy or Intune. See the admin guide.

System requirements

  • Windows 10 or Windows 11, 64-bit (x64).
  • Microsoft Edge WebView2 Runtime. It is built into Windows 11 and already on Windows 10 PCs that get updates. If it is missing, SoloCopy offers to open Microsoft's WebView2 page.
  • No .NET install needed: the app brings everything it needs.
  • The MSI installs for all users of the PC, so Windows asks for admin rights.

For offices and IT teams

Group Policy and Intune

ADMX templates for four policies: report-only mode, allowed folders, blocked network drives and the delete history folder. The app re-reads them before every search and delete.

Central audit folder

Save every user's delete history to a folder that IT chooses, for example on a file server. If it cannot be reached, the app writes locally and no entry is lost.

Silent MSI install

Per-machine install to C:\Program Files\SoloCopy:

msiexec /i SoloCopy-0.9.0-x64.msi /qn
